## Getting Started
### Prerequisites
- **Flutter SDK** >= 3.8.1 (as specified in `pubspec.yaml`).
- **Dart** >= 3.0.0.
- An IDE such as **Android Studio**, **VS Code**, or **IntelliJ** with Flutter plugins.

### Installation
```bash
# Clone the repository (if you haven't already)
git clone <repository‑url>
cd ShopZone-SmartE-Commerce-Platform-main

# Install dependencies
flutter pub get
```

### Assets
1. The splash screen uses the logo generated earlier. Place the logo image at:
   `assets/images/shop_zone_logo.png`
2. Ensure the asset is declared in `pubspec.yaml`:
```yaml
flutter:
  assets:
    - assets/images/shop_zone_logo.png
```

### Running the App
```bash
# Run on a connected device or emulator
flutter run
```
The app will start with the animated splash screen, then navigate automatically to the home page.

## Project Structure Details
- **`main.dart`** – Sets up `MaterialApp`, registers routes (`SplashScreen`, `HomePage`, `ProductDetails`, `UpdateProductPage`), and disables the debug banner.
- **`splash_screen.dart`** – Implements a `StatefulWidget` with `AnimationController` for scale and fade animations. After a 3‑second timer it navigates to `HomePage.id`.
- **Product feature** – Contains screens for listing products, showing details, and editing products. Uses `flutter_bloc` for state management (already wired in the original repo).
- **Styling** – Uses a dark premium background on the splash screen, custom font (`Roboto`), and subtle text shadows for a polished look.

## Customising the Splash Screen
- **Animation duration** – Change `duration: const Duration(seconds: 2)` in `AnimationController`.
- **Delay before navigation** – Adjust `Timer(const Duration(seconds: 3), …)` to a different duration.
- **Background color** – Modify `backgroundColor` in the Scaffold.
- **Logo** – Replace `shop_zone_logo.png` with your own branding.

## Known Issues & Fixes
- **Missing asset error** – Ensure the logo image exists at the path above and the `assets` entry in `pubspec.yaml` is uncommented.
- **Route not found** – Verify that `SplashScreen.id` and other route IDs are correctly imported in `main.dart`.
